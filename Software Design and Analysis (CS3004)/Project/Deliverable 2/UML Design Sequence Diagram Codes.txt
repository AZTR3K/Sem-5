UC: 02
@startuml
title UC-02: Attack Enemy

actor Player
participant "Game System" as Game

' Step 1
Player -> Game: 1. Press attack button
Game -> Game: 1.1 Play attack animation and check collision

' Step 2
alt Attack connects
    Game -> Game: 2.1 Apply damage to enemy, reduce health
else Attack misses
    Game -> Game: 2.2 No damage registered
end

' Step 3
Game -> Player: 3. Show hit or miss feedback (animation, sound)

@enduml

UC: 04
@startuml
title UC-04: Dodge Attacks

actor Player
participant "Game System" as Game
participant "Enemy AI" as EnemyAI

== Dodge Initiation ==
Player -> Game: 1. Press dodge button
Game -> Game: 1.1 Play dodge animation
Game -> Game: 1.2 Grant temporary invulnerability frames (i-frames)

== Attack Phase ==
EnemyAI -> Game: 2. Perform attack targeting player
Game -> Game: 2.1 Check dodge timing
alt Dodge successful
    Game -> EnemyAI: 2.2 Register attack miss
    Game -> Player: 2.3 Maintain invulnerability
else Dodge failed
    Game -> Player: 2.4 Apply damage
end

== Postcondition ==
Game -> Game: 3. End invulnerability frames

@enduml
